# tidepool

A playground for [Jumper](https://github.com/KingKongRobotics/jumper), the open-source crab robot.

Built for the Crab Robot Open-source Challenge 2026. Everything here runs in simulation
(MuJoCo), no hardware required.

## Status

Early days. Nothing to run yet — see the commit log for what's moving.

## Requirements

- macOS (Apple Silicon) or Linux
- Python 3.11+
- Docker, only if you want to build deployable `.app` bundles
